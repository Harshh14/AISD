Cashback Calculation Policy & Edge Cases

  • Zero Float Arithmetic: All financial calculations use integer paise internally (₹1 = 100 paise) with floor division (//).
  • Multipliers: PRIME applies 1.5x multiplier (bps * 150 // 100), PREMIUM applies 2.0x multiplier (bps * 200 // 100).
  • Monthly Caps: Enforced per student, per merchant category, per calendar month. Once a student reaches the cap, subsequent payments earn 0 cashback.
  • Idempotency: Every payment carries a unique idempotency key. Duplicate submissions return the existing transaction without double deduction.
  • Top-ups: Wallet top-ups receive exactly 0% cashback and are exempt from category caps.
